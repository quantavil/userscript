# Search Engine Quick Switcher

[![GitHub](https://img.shields.io/badge/GitHub-quantavil%2Fuserscript-181717?logo=github&logoColor=white)](https://github.com/quantavil/userscript)

A minimal dark floating switcher with SVG icons for Brave/Yandex/Bing/DDG/YouTube/Google.

## Features

- Floating panel on search result pages
- Click icons to switch engines with same query
- Cycle to next engine with handle button
- Dark theme with smooth animations

Install via Tampermonkey from the main.js file.
